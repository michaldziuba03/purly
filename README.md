# purly

SaaS platform for managing your brand links. Under active development. Primary goal of this project is to create sample that does more than just simple CRUD.

### Run docker

```sh
docker compose up
```

### Run migrations

```sh
pnpm migration:up
```

### Run development servers

```sh
pnpm dev
```
